# Название проекта

Проект для анализа банковских транзакций. Загружает данные из Excel-файла, получает курсы валют с сайта ЦБ РФ и цены акций через API Twelve Data, формирует JSON-ответ для главной страницы с информацией по картам, топ-транзакциями, а также рассчитывает выгодные категории кешбэка и траты по категориям за последние три месяца.

## Разработка

### Требования
Для установки и запуска проекта необходим Python версии 3.12 или выше.

### Структура проекта

bank_utils/
├── data/
│   └── operations.xlsx          # Исходные данные с транзакциями
├── src/
│   ├── utils.py                 # Утилиты: загрузка данных, API, приветствие
│   ├── views.py                 # Главная страница (JSON-ответ)
│   ├── services.py              # Сервис: выгодные категории кешбэка
│   ├── reports.py               # Сервис: траты по категории за 3 месяца
│   └── main.py                  # Точка входа, запуск всех функций
├── tests/
│   ├── conftest.py              # Фикстуры для pytest
│   ├── test_utils.py            # Тесты для utils.py
│   ├── test_views.py            # Тесты для views.py
│   ├── test_services.py         # Тесты для services.py
│   └── test_reports.py          # Тесты для reports.py
├── .env.example                 # Шаблон переменных окружения
├── .flake8                      # Конфигурация линтера
├── .gitignore                   # Игнорируемые Git файлы
├── pyproject.toml               # Конфигурация black, isort, mypy, pytest
├── requirements.txt             # Зависимости проекта
└── README.md                    # Документация проекта

### Установка зависимостей
Для установки зависимостей, выполните команду:

pip install -r requirements.txt

## Тестирование
Для тестирования всех модулей используется Pytest.
Чтобы протестрировать проект введите команду "pytest" или "pytest --cov=src" в терминале
